# UEFN-Verse

A collection of Verse devices for Unreal Editor for Fortnite (UEFN), each one
self-contained and ready to drop into a project.

## Devices

| Device | What it does |
| --- | --- |
| [Cinematic Event Array](devices/cinematic-event-array/) | Plays a list of cinematic sequences on a real-world UTC schedule, staying in sync across server restarts. |

## Using a device

1. Open the device's folder above and read its README for the settings it exposes.
2. Copy the `.verse` file into your UEFN project's Content folder.
3. Build Verse code in UEFN (**Verse → Build Verse Code**).
4. Drag the newly compiled device from the Content Browser into your level, then
   fill in its options in the Details panel.
